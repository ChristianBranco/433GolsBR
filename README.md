# 433GolsBR
Jogo de navegador: gire, sorteie um dos 20 clubes com mais Brasileirões e escolha jogadores para montar um 4-3-3 que some exatamente 433 gols na Série A. São 953 jogadores dos anos 70 a 2026, coringas (girar de novo, olheiro, substituição), filtro por era e tabela completa. Feito em HTML/JS puro, sem dependências.
